# Introduction to Networking

**Date: ** 11 November 2026

**What I Learned Today**

- Networking is how computers and devices communicate with each other.
- The basic building blocks of a network include:
  - Devices (computers, routers, switches)
  - Media (cables or wireless)
  - Protocols (rules for communication)

 Key Terms

- **IP Address** → A unique number that identifies a device on a network
- **Router** → A device that connects different networks together
- **Switch** → A device that connects devices within the same network

## Simple Understanding

Networking is like a postal system for computers.  
Each device has an address (IP address), and data is sent in small packages (packets) following certain rules (protocols).
